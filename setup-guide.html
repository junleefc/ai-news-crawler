AI 뉴스 데일리 크롤러 세팅 가이드

매일 아침 8시(KST) 해외 AI 뉴스 자동 수집 → Claude 한글요약 → 구글시트 저장 + 슬랙 발송. GitHub 클라우드에서 돌아 컴퓨터가 꺼져 있어도 매일 실행됩니다.

크롤링(RSS·구글뉴스) → Claude 한글요약 → 구글시트 저장 → 슬랙 #ai_news 발송
└─ 매일 08:00 KST · GitHub Actions cron ─┘

1 Anthropic API 키

  • console.anthropic.com → API Keys → 새 키 발급
  • sk-ant-... 복사 → 나중에 시크릿 ANTHROPIC_API_KEY 에 사용

2 슬랙 Webhook (#ai_news 연결)

  1. api.slack.com/apps → Create New App → From scratch
  2. 왼쪽 메뉴 Incoming Webhooks → 활성화 ON
  3. Add New Webhook to Workspace → 채널 #ai_news 선택
  4. 생성된 URL 복사 → 시크릿 SLACK_WEBHOOK_URL 에 사용

3 구글 시트 + 서비스 계정

  1. 구글 시트 새로 생성 → URL의 /d/ 와 /edit 사이 문자열이 SHEET_ID
  2. console.cloud.google.com → 프로젝트 생성 → Google Sheets API 사용 설정
  3. 서비스 계정 생성 → 키 → JSON 다운로드
  4. JSON 안의 client_email(…iam.gserviceaccount.com)을 시트에 편집자로 공유 ← 꼭!
  5. JSON 파일 전체 내용 → 시크릿 GOOGLE_SERVICE_ACCOUNT_JSON 에 사용

4 GitHub 저장소 + 시크릿 등록

이 폴더를 GitHub 저장소에 올린 뒤, Settings → Secrets and variables → Actions 에서 4개 등록:

Secret 이름값
ANTHROPIC_API_KEYsk-ant-…
SLACK_WEBHOOK_URLhttps://hooks.slack.com/services/…
SHEET_ID구글 시트 ID
GOOGLE_SERVICE_ACCOUNT_JSON서비스계정 JSON 전체

▶ 실행 & 테스트

  • 자동: 매일 08:00 KST 실행
  • 수동 테스트: GitHub 저장소 → Actions → "Daily AI News Digest" → Run workflow
  • 로컬 테스트: cp .env.example .env → 값 채우고 python main.py
